## ⭐ Featured Projects

### 📍 [CzyPrzejadę](https://github.com/GonsiorHack/czyPrzejade) `Startup in Progress`
> **Actively seeking contributors, pre-seed investors, municipal partners and cloud infrastructure sponsors.**

A scalable urban accessibility and micromobility platform engineered to navigate pedestrians with restricted mobility (wheelchair users, seniors, and parents with strollers) around architectural barriers. Combines Computer Vision surface classification with multi-criteria spatial dual-routing to generate step-free transit corridors.

- **Dual-Routing Client & GIS Integration:** Architected the mobile-first PWA frontend in **Svelte** and **Leaflet**, implementing visual route comparisons, geocoding pipelines, and real-time rendering of spatial avoidance polygons.

- **Full-Stack ML Pipeline:** Bridged asynchronous **FastAPI** backend services with a **MobileNetV2** visual classification engine, transforming street-level surface quality into dynamic graph-routing penalty weights.

- **R&D & Scalable Infrastructure:** Currently transitioning routing from third-party endpoints to a dedicated self-hosted GIS cluster (**Valhalla / OSRM**) and expanding R&D on overhead 3D obstacle segmentation for municipal pilot deployments.

### 🦊 Zora App
An open-source, spaced-repetition learning platform that pairs a lightning-fast native backend with a modern GUI. Evolved from a university project into a full-fledged application.
- **Cross-Layer Integration:** Successfully bridged raw, native **C++** execution (handling the SM-2 algorithm and Levenshtein distance) with a modern reactive frontend.

- **AI Data Pipeline:** Designed the data flow to ingest structured **JSON** files, allowing users to effortlessly generate custom flashcard decks using LLMs.

- **Resilient Data Architecture:** Implemented real-time state serialization to disk, ensuring zero data loss during active sessions while maintaining <100ms startup times.

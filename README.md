## ⭐ Featured Projects

---
### 🦊 Zora App
An open-source, spaced-repetition learning platform that pairs a lightning-fast native backend with a modern, lightweight GUI. Evolved from a terminal-based university project into a full-fledged application.
* **High-Performance Core Engine:** Engineered a native **C++** backend executing the **SM-2 algorithm** for dynamic review scheduling and the **Levenshtein distance** metric for typo-tolerant, intelligent answer verification.
* **Resilient Data Architecture:** Implemented real-time state serialization to disk, ensuring zero data loss during active learning sessions.
* **AI Data Pipeline:** Designed the data flow to natively ingest structured **JSON** files, allowing users to effortlessly generate and import custom flashcard decks using LLM prompts (ChatGPT, Claude, Gemini).
* **Cross-Layer Integration:** Successfully bridged raw, native C++ execution with a modern **Svelte** frontend, maintaining extreme performance (<100ms startup) and a clean, responsive user experience.

### ♟️ [En Passant](https://github.com/GonsiorHack/tadeusz-kosciuszko-2026.git)
A gamified educational platform focused on **cybersecurity** built during a hackathon. As the leader of the "Gonsior" collective, I was responsible for designing and overseeing the underlying software architecture.
* **Rapid Architecture Design:** Structured the logic-based progression systems and data flow under strict a 24-hour hackathon deadline.
* **State Management:** Managed the complex state logic and narrative branching of interactive, chess-themed dialogue modules.
* **Tech Stack:** Built with **SvelteKit 5**, utilizing native file-based routing to ensure scalability and smooth data handling.

### 🌐 Commercial Web Development & E-Commerce
A collection of fullstack and web development projects focusing on UX/UI, data integrity, and business optimization.
* **RW Hunt (E-commerce Optimization):** Redesigned the UI/UX and managed the digital content strategy for a specialized e-commerce platform, driving a **+198% increase in organic reach (29.3k views)** entirely without paid advertising.
* **RW Hunt (Data & Content):** Handled specialized product databases and streamlined online customer queries, bridging technical maintenance with marketing goals.
* **Healthcare SPA (Nursing Services):** Architected a professional-grade Single Page Application using **SvelteKit** and **TypeScript** for robust type safety across the entire stack.
* **Secure Backend Flows:** Integrated a custom reservation engine specifically designed to parse and handle external patient data flows securely and efficiently.

### ⛽ [ZaWahę](https://github.com/sh3kda/zawahe-mobile-app-design)
A comprehensive mobile ecosystem designed to eliminate information asymmetry in the fuel market via crowdsourcing. 
* **Data Flow Modeling:** Designed the structural logic for a "One-Tap Update" mechanism and geofencing-based **Smart Reporting** features.
* **Logic-Driven Features:** Mapped out the data architecture for a **Social Billing** module aimed at dynamically splitting travel costs among users.
* **Full-Product Perspective:** Prototyped the high-fidelity UI in **Figma**, leveraging my communication background to create interfaces that translate complex backend datasets into easily digestible user views.
